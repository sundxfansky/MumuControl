## 1.1.0 远程访问与安全

- 本机 HTTP 与远程 HTTPS 使用独立监听：本机只绑定 `127.0.0.1`；远程默认关闭，账户初始化前不会监听远程端口。
- 账户初始化、远程开关与端口、账户修改、证书下载和 Windows 开机启动均要求本机已登录会话；远程 HTTPS 即使从本机回环地址访问也不获得本机管理权限。
- 账户密码使用 PBKDF2-HMAC-SHA256 600,000 次和随机盐；安全目录只授予当前 Windows 用户与 SYSTEM 权限；HTTPS 私钥使用当前 Windows 用户 DPAPI 加密；会话仅在内存中，带 HttpOnly/Secure/SameSite Cookie、CSRF、来源 IP 绑定、空闲/绝对过期和登录失败限速。
- 远程状态不返回本机 `MuMuManager.exe` 完整路径；远程只可执行模拟器、任务和状态相关接口。
- 证书下载只返回无私钥的 DER 公钥；安全审计不记录密码或会话 token。
- 隔离安全回归 **60/60** 通过，覆盖初始化范围、Host/Origin/Forwarded 防护、认证与会话隔离、CSRF、登录限速、证书公钥导出、凭据持久化/重启、旧密码拒绝、远程关闭、开机启动安全。未修改生产账户、Windows 防火墙或生产启动项。

## 内存对比

相同 .NET 8 自包含单文件、11 个实例、默认 5 秒轮询，未开启画面自动刷新：

| 发布方式 | EXE 大小 | headless 工作集 |
| --- | --- | --- |
| 单文件内部压缩 | 约 74.5 MiB | 约 124–141 MiB |
| 关闭内部压缩（默认） | 约 166 MiB | 约 50–60 MiB |

工作集是本机短期采样，不是长期稳定性或各设备内存上限保证。未开展数小时压力测试；桌面显示时还会有 WebView2 子进程。代码为命令、输出、并发、图片请求和日志设置上限；正常成功轮询不写配置或日志。
